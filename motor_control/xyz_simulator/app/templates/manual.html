Error Codes

The following table lists the error codes that may be encountered during motor operation. Each code corresponds to a specific issue that needs to be addressed.

No Code Description
1 0x01 Lower Limit
2 0x02 Upper Limit
3 0x03 Motor driver error
4 0x04 CAN communication failed
5 0x05 Position encoding error
6 0x06 Home sensor error
7 0x07 Motor overload
8 0x08 Position reach limit (In torque mode, motor reaches the target position)
9 0x09 SPI driver supply voltage low
10 0x0A SPI driver supply voltage high
11 0x0B SPI driver temperature high
12 0x0C SPI driver overheat
13 0x0D SPI driver overvoltage
14 0x0E SPI driver overcurrent
15 0x0F SPI driver command execute disable
No Code Description
16 0x10 SPI driver EEPROM error
17 0x11 Driver parameters setting failed
18 0x12 Rotation stroke over run
19 0x13 EEPROW read/write error
20 0x14 Encoder not response
21 0x15 Encoder error on homing
22 0x16 Home time-out
23 0xC1 Motor is busy
24 0xC2 Motor parameters not set or Homing command was not executed
25 0xC3 Motor position is at the limit of the requested move direction
26 0xC4 Out of resources for specified speed and acceleration time
27 0xC5 Invalid speed command
28 0xC7 No valid position saved in NVM or HOming command was not executed
29 0xC8 Earthquake in progress
30 0x41 CAN_FD_ERROR_TX_RX_WARNING_STATE
