## XYZ Simulator

### Description
This is the XYZ simulator tool for CSOS unit to control motor movement and provoide some information such as error code information. 
This can be used for testing and moving the motors.


### Version
* 1.0.0.0
    - base version of the simulator
* 1.0.0.1
